# Project Starter Template

A repeatable project skeleton built around an AI-first workflow: **play and prototype first, then transition immediately into structured production development on GitHub.**

## Standard Folder Structure
- `ai-github-project-starter.pptx` — Walkthrough presentation deck stored at the root for anyone starting a new project.
- `docs/00-project-setup-guide.md` — Living process guide updated as new stages, prompt patterns, and lessons are added.
- `data/` — Sample inputs, schemas, and baseline test fixtures used to validate models early.

## AI-First Build Loop
1. **Play & Prototype First:** Bat ideas around in Google AI Studio until you have a working prototype that proves out what the app actually needs.
2. **Scaffold via AI Commands:** Ask AI to generate the directory and starter file commands so you paste and run instead of typing boilerplate by hand.
3. **Codify Specs & Fixtures:** Have AI translate your prototype's proven rules into `docs/` specifications and `data/` test files.
4. **Build & Evolve:** Push milestones to GitHub, build the production version, and update `docs/00-project-setup-guide.md` as you progress.
